Case 01 · AI-native migration

3개 레거시 백엔드의 구독 도메인을 단계적으로 MSA로 통합하다.

실제 운영 트래픽을 받는 전용 서비스로 9개 API operation을 이전했습니다. AI 에이전트로 호출 경로와 계약 차이를 빠르게 좁히고, 범위·위험 판단과 운영 검증은 직접 책임졌습니다.

  • 역할 마이그레이션 실행 책임자
  • 결과 9개 API 전환 · 클라이언트 변경 0
  • 상태 일부 운영 트래픽 전환 완료

Case 02 · Product system

제휴 매장당 월 1회 무료 마케팅을, 사장님이 앱에서 직접 운영하게 만들다.

사장님 앱 리뉴얼의 핵심 경쟁 포인트를 백엔드 상태 머신으로 구현했습니다. 현재 단계·문구·가능한 행동을 서버가 결정해 iOS와 Android가 같은 정책을 보도록 만들었습니다.

  • 역할 백엔드 구현 책임
  • 핵심 시간·상태 기반 운영 플로우
  • 상태 백엔드 완료 · 앱 연동 및 QA 진행

Case 03 · Affiliate

고품질 리뷰를 구매 전환과 연결한 어필리에이트 시스템을 구축하다.

팝로그 작성자의 콘텐츠를 거쳐 발생한 구매를 추적하고 보상하는 흐름을 처음부터 끝까지 연결했습니다. 링크 발급부터 결제 출처 저장, 상태 변경, 월 정산까지 하나의 운영 시스템으로 만들었습니다.

Working principles

좋은 백엔드는 배포 이후의 경험까지 책임집니다.

실제 경로를 끝까지 봅니다.

사용자 화면부터 API, 비동기 작업, 데이터 저장까지 소비자와 작성자 경로를 함께 추적합니다.

운영에서 확인합니다.

배포 완료가 아니라 운영 환경과 실제 앱에서 정상 동작하는 것까지 검증합니다.

AI의 속도에 판단을 더합니다.

분석과 구현 초안은 가속하되, 설계 결정과 결과의 책임은 직접 집니다.
